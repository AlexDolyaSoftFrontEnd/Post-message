# Comments App (React + TypeScript + Vite)

Клиентское приложение для добавления и отображения комментариев.
Реализовано на React и TypeScript с использованием Vite, CSS Modules и BEM-нейминга.
Интерфейс выполнен в минималистичном стиле с акцентом на типографику, отступы и UX.

---

## Функциональность

* Добавление комментариев (имя и текст)
* Контролируемая форма
* Базовая валидация (пустые поля)
* Отображение списка комментариев
* Чистое разделение логики и UI
* Глобальные CSS-переменные для стилизации

---

## Структура проекта

```
src/
├── App.tsx
├── main.tsx
│
├── styles/
│   ├── variables.css
│   └── base.css
│
└── components/
    ├── CommentsBlock/
    │   ├── CommentsBlock.tsx
    │   └── CommentsBlock.module.css
    │
    ├── CommentForm/
    │   ├── CommentForm.tsx
    │   └── CommentForm.module.css
    │
    └── CommentItem/
        ├── CommentItem.tsx
        └── CommentItem.module.css
```

---

## Архитектура

* `CommentsBlock` — контейнерный компонент, хранит состояние комментариев
* `CommentForm` — компонент формы ввода
* `CommentItem` — презентационный компонент комментария
* Единый источник состояния
* Логика и представление разделены

---

## Стилизация

* Все цвета, размеры и отступы вынесены в CSS-переменные
* Компоненты используют только дизайн-токены
* Отсутствуют жёстко зашитые значения
* Проект подготовлен для:

  * добавления тёмной темы
  * темизации
  * расширения в дизайн-систему

## Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу:

```
http://localhost:5173
```

---

## Сборка проекта

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```
